# Viikko 4 – Koodinimigeneraattori

Vite + React -sovellus generoi käyttäjälle hauskan koodinimen. Kirjautuessa se tarkistaa ensin selaimen Local Storagen `codename`-avaimen. Jos nimeä ei ole tallennettu, sovellus luo uuden koodinimen ja tallentaa sen. Uloskirjautumisen jälkeen samalla selaimella kirjautuminen palauttaa saman nimen.

## Käynnistä kehitystilassa

```bash
npm install
npm run dev
```

## Rakenna ja esikatsele julkaisuversio

```bash
npm run build
npm run preview
```
